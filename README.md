### 🚀 Highlighted Work

#### 🧠 [3D Medical Imaging Pipeline (BraTS)](https://github.com/YasYes/brats-3d-segmentation)
*End-to-end PyTorch/MONAI pipeline for 3D volumetric segmentation of brain tumors.*
- **Focus:** Balancing local boundary delineation with global topological context using 3D U-Nets and sliding window inference.
- **Honest Metric:** Reached a preliminary validation Dice score of ~0.86 on initial inference tests.

#### 👁️ Retinal Vessel Segmentation (SDAE)
*Robust feature extraction for fine tubular structures.*
- **Focus:** Designed a Stacked Denoising Autoencoder to preserve complex micro-vasculature under extreme domain noise, prioritizing geometric truth over superficial metrics.

#### 🛰️ Industrial R&D @ Thales
*The code is under NDA, but the impact is real.*
- **Focus:** Adapted a 13-channel satellite super-resolution model to standard 3-channel RGB. 
- **Engineering:** Solved severe CUDA memory bottlenecks via Automatic Mixed Precision (AMP) and spatial tiling to process 8,500+ high-res image pairs, driving a 37% reduction in LPIPS error.
